# X&O — Tic Tac Toe

**A Classic Game. A Modern Experience.**

X&O is a browser-based Tic Tac Toe game built with an interactive interface, customizable themes, and multiple gameplay modes. It brings the traditional X and O experience into a modern web application.

Players can enjoy a friendly match with another player or challenge the computer through the AI game mode.

## Features

- **Multiple Game Modes**
  - Player vs Player
  - Player vs AI

- **Custom Player Names:** Enter personalized names before starting a multiplayer game.

- **Theme Customization:** Choose from 9 different visual themes.

- **Interactive Welcome Screen:** A dedicated interface for selecting game modes.

- **Turn Indicator:** Displays the current player's turn.

- **Winner Detection:** Automatically identifies winning combinations and draw situations.

- **Confetti Animation:** Celebrates winning moments with visual effects.

- **Game Controls:** Reset the board or start a new game.

- **Contact Section:** Direct links to the developer's social media and email.

- **Responsive Interface:** Designed for different screen sizes.

## How to Play

1. Open the application.
2. Select Player vs Player or Play with AI.
3. Enter player names if playing with another person.
4. Start the game.
5. Take turns placing X and O on the 3×3 board.
6. Get three matching symbols in a horizontal, vertical, or diagonal line to win.
7. Start a new game and play again.
